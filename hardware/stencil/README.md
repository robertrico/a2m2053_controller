# Stencil fixture

A 3D-printed jig that holds a Disk Hamr rev 1.0 board and the PCBWay solder
paste stencil in register, for pasting the top side. Generated by
[stencilframer](https://hyperglitch.com/articles/stencilframer) (Igor Brkic,
MIT) from the board outline Gerber, with OpenSCAD doing the geometry.

The board itself is hand-solderable (`FABRICATION.md`, "Rule:
hand-solderable"); the stencil just makes the five-board run quicker.

## Parts

| File | What |
|---|---|
| `holder.stl` | Fixture. Base plate with a 1.6 mm pocket shaped like the board (0.1 mm clearance) and, above it, a 160 x 170 mm pocket for the stencil. One finger hole on the long edge to lift the board out. |
| `frame.stl` | Optional frame that sits on the stencil edge inside the fixture pocket and holds it flat. Chamfered corners, 5 mm wide, 5 mm tall. Same size as the pocket on purpose: the press fit is the only thing holding it in. `FRAME_OFFSET` lowers it if a print will not seat. |
| `*.png` | OpenSCAD previews, `make preview`. |
| `check_stencil.py` | Aperture-to-sheet-edge check, `make check`. See below. |

Outside dimensions of the fixture are 170 x 180 mm (stencil plus a 5 mm
wall), 4.6 mm tall. Check that it fits the printer bed before slicing.

## Inputs

| Thing | Value | Source |
|---|---|---|
| Outline | `hardware/kicad/fabrication/a2m2053-Edge_Cuts.gbr` | Same Gerber PCBWay built from. The `.kicad_pcb` has two Bezier (`gr_curve`) edges that stencilframer cannot parse; the Gerber has them flattened. |
| Board | 100 x 110 mm, 1.6 mm | Outline bounds, board stackup |
| Stencil | 160 x 170 mm, T = 0.12 mm stainless, frameless | PCBWay order |
| Margins | 30 mm all round | (160 - 100) / 2 and (170 - 110) / 2, PCBWay centred the apertures on the sheet: the four caliper readings below matched on the real stencil, 2026-11-07. |
| Side | Top only | All 46 footprints are on F.Cu. No `--mirror`. |

## Checking the stencil before printing

stencilframer never reads the paste layer; it places the sheet pocket from
the outline and the margins alone. `make check` runs `check_stencil.py`,
which reads the F_Paste and Edge_Cuts Gerbers and prints, for the aperture
nearest each sheet edge, the expected distance from that aperture's outer
edge to the sheet edge. It also draws `check_stencil.svg` / `.png` with the
four dimensions marked. With 30 mm margins:

| Edge | Aperture | Expected, aperture outer edge to sheet edge |
|---|---|---|
| left | U2 pin, 2.05 x 0.60 | 32.82 mm |
| right | U1 pin, 0.60 x 2.05 | 35.38 mm |
| top | R2 pad, 1.75 x 1.12 | 36.46 mm |
| bottom | A1 castellation, 3.80 x 2.20 | 30.65 mm |

Top and bottom are as in KiCad's board view, component side up. Caliper
the same four on the stencil. Expected minus measured is the margin
correction for that side; pass the corrected margins in and rebuild:

```
make MARGIN_L=29.6 MARGIN_R=30.4 MARGIN_T=30 MARGIN_B=30 check
make MARGIN_L=29.6 MARGIN_R=30.4 MARGIN_T=30 MARGIN_B=30
```

A laser-cut sheet holds aperture-to-edge to a few hundredths, so one check
and one print is the expected path. If the two sides of an axis disagree by
more than ~0.1 mm the sheet is not square and the pocket clearance
(`--stencil-offset`, 0.1 mm) needs to grow to the larger error.

Stencil thickness does not enter the model: the stencil pocket is 2 mm deep
and the frame holds the sheet down.

## Tools

- stencilframer checkout, default `../../../stencilframer/stencilframer.py`
  (`STENCILFRAMER=` in `.env.local` to move it). Python 3, no packages.
- OpenSCAD on `PATH`, or `OPENSCAD=` in `.env.local`. On macOS the Homebrew
  `openscad` cask is disabled (Gatekeeper, 2026-09); `brew install --cask
  openscad@snapshot` installs the 2026.10 nightly and links `openscad`.

```
make            # holder.stl, frame.stl
make preview    # holder.png, frame.png
make check      # expected caliper readings, check_stencil.png
make holder.scad   # OpenSCAD source, to edit by hand
```
